# Data-Analyst-Task-5

Task 5: Exploratory Data Analysis (EDA)

Project Overview

This project focuses on Exploratory Data Analysis (EDA) to extract meaningful insights from a dataset using statistical methods and data visualization techniques.

Objective

To identify patterns, trends, relationships, and anomalies in the dataset through visual and statistical exploration.

Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

Dataset

- Titanic Dataset

Tasks Performed

- Loaded and explored the dataset.
- Checked dataset information using "info()".
- Generated statistical summaries using "describe()".
- Analyzed categorical columns using "value_counts()".
- Created histograms and boxplots.
- Used scatterplots to identify relationships.
- Created pairplots and correlation heatmaps.
- Identified patterns, trends, and outliers.
- Summarized key observations and findings.

Key Learnings

- Understanding data distribution.
- Identifying correlations between variables.
- Detecting outliers and anomalies.
- Performing univariate, bivariate, and multivariate analysis.
- Extracting meaningful insights through visualization.

Conclusion

This project helped develop practical skills in Exploratory Data Analysis using Python. It provided insights into dataset patterns, relationships, trends, and anomalies through statistical analysis and visualizations.
